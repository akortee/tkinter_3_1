## Описание проекта

Программа представляет собой графическое десктопное приложение для математического моделирования и визуализации аттрактора Лоренца в реальном времени. Реализована плавная двумерная проекция движения точки с возможностью интерактивной настройки системных параметров ($\sigma$, $r$, $b$) прямо во время работы программы.

## Функциональные возможности

### Основной функционал
- Анимация в реальном времени: Непрерывная отрисовка траектории движения точки (эффект "бабочки Лоренца").
- Интерактивное управление: Изменение параметров $\sigma$ (Sigma), $r$ и $b$ с помощью удобных слайдеров без перезапуска программы.
- Сброс состояния: Кнопка для очистки холста и возврата точки в начальные координаты (с защитой от математического "залипания" в нулях).

### Дополнительный функционал
- Координатная сетка: Наглядное отображение масштаба на фоне.
- Темная тема: Стильный и контрастный интерфейс (темный фон, бирюзовые линии графика).
- Защита от ошибок: Корректная обработка закрытия окна без системных ошибок в терминале.

- **Python:** 3.8 или выше
- **Операционная система:** Windows / macOS / Linux
- **Библиотеки:** 
  - `tkinter` (встроена в стандартную библиотеку Python)

## Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/akortee/tkinter_3_1.git
cd tkinter_3_1
```

### 2. Создание и активация виртуального окружения
Windows:
```bash
python -m venv venv
venv\Scripts\activate
```

macOS/Linux:
```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 4. Запуск программы
Windows:
```bash
python main.py
```

macOS/Linux:
```bash
python3 main.py
```

### 5. Управление
- **Ползунок Sigma ($\sigma$):** Регулирует скорость закручивания спиралей.
- **Ползунок r ($r$):** Критический параметр. При $r > 24.7$ система переходит в хаотический режим (рисуется "бабочка"). При малых значениях точка стремится к центру.
- **Ползунок b ($b$):** Влияет на размер и пропорции аттрактора.
- **Кнопка "Сбросить":** Очищает экран и применяет текущие настройки ползунков к новой линии.

```text
lorenz_attractor/
├── .gitignore
├── README.md

    ├── app.py
```

**Назначение основных модулей:**
- `main.py` — точка входа в программу.
- `app.py` — главный класс приложения (окно, цикл обработки событий).
- `animation_model.py` — класс для расчета координат аттрактора Лоренца.
- `renderer.py` — класс для отрисовки графики на холсте.
- `controls.py` — элементы пользовательского интерфейса (слайдеры, кнопки).

## Пример использования

### Запуск программы
```bash
python main.py
```

### Работа с интерфейсом
1. Установите ползунок "Параметр r" на значение $28.0$ или выше.
2. Нажмите кнопку "Сбросить".
3. Наблюдайте за формированием хаотического аттрактора. Попробуйте плавно менять параметр $\sigma$ во время отрисовки, чтобы увидеть, как траектория адаптируется в реальном времени.
